## What it does

`main.ts` writes one original one-line joke about office life to `/output/entry.txt`:

> I asked IT to fix my computer; they told me to turn it off and on again, so I did the same to my career.

The joke is deterministic — the program writes the same line on every run, so both grading runs produce the identical entry.

## Run it

Requires Node 22.18 or later, nothing to install:

```sh
node main.ts
cat /output/entry.txt
```

## How the joke is built

- **Setup:** an office worker asks IT to fix a broken computer.
- **Turn:** the classic IT advice — turn it off and on again — gets applied to the worker's career instead of the machine.
- **Punchline last:** "so I did the same to my career" lands the reboot on the job itself.

The line is 104 characters, inside the competition's 1–200 character gate.
